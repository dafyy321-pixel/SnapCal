🔧 useCache Hook 无限循环修复报告

✅ 修复完成！Maximum update depth exceeded 错误已解决

📋 问题分析

原始错误： Maximum update depth exceeded
原因： useCache Hook 中的 useEffect 依赖项包含在每次渲染时都会变化的函数引用

🛠️ 修复方案

  • 使用 useRef 存储变化的依赖：将 fetcher 和 cacheOptions 存储在 ref 中，避免依赖变化
  • 优化 useCallback 依赖数组：移除会变化的函数依赖，只保留稳定的依赖
  • 优化 useEffect 依赖数组：移除会导致循环的函数依赖
  • 修复类型问题：为缓存操作添加正确的泛型类型

🔍 具体修改

1. fetchData 函数 (第50-99行)

修改前： useCallback(..., [key, fetcher, cacheOptions])
修改后： useCallback(..., [key]) + 使用 ref 获取最新值

2. mutate 函数 (第102-110行)

修改前： useCallback(..., [key, fetchData, cacheOptions])
修改后： useCallback(..., [key, fetchData])

3. preload 函数 (第113-120行)

修改前： useCallback(..., [key, fetcher])
修改后： useCallback(..., [key])

4. useEffect 依赖优化 (第123-170行)

修改前： 所有 useEffect 都包含 fetchData 依赖
修改后： 移除 fetchData 依赖，避免循环触发

5. useBatchCache Hook (第352-441行)

修改前： queries 作为依赖导致频繁重新执行
修改后： 使用 ref 存储 queries，空依赖数组
